# HamaSwiftly

**Your Home, Swiftly Found** - A modern rental search platform for Nairobi and its outskirts.

[Live Demo](https://s-nailantei.github.io/hamaswiftly/)

## Features

- **Search & Filter** - Find rentals by location, price, bedrooms, property type, and area
- **30+ Properties** - Listings across Nairobi including:
  - CBD, Westlands, Kilimani, Karen, Lavington
  - Eastlands (Umoja, Donholm, Buruburu, Kayole, Embakasi)
  - Thika Road (Kasarani, Roysambu, Kahawa, Garden City)
  - Kabete, Uthiru, Ruiru, Kitengela, Kajiado
- **User Accounts** - Tenants and Landlords can create accounts
- **Property Listings** - Landlords can list their properties
- **Premium Features** - Direct phone & WhatsApp contact with landlords
- **Map View** - Interactive map centered on Nairobi
- **Favorites** - Save properties you like
- **Responsive Design** - Works on mobile and desktop

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Leaflet.js (Maps)
- LocalStorage (Database)
